PIN Entry Numpad

Reusable component used by lock screen, manager override, and exit POS. Big 72pt buttons per POS "big and obvious" principle. Auto-submits when 4 digits entered.

Light Idle State
Default state. Empty PIN dots, large numpad buttons, cancel option at bottom.
Dark Idle State
Dark mode. Button backgrounds visible with posSurfaceContainerLow color.
Light Error State
Invalid PIN entered. Red error message below dots. Dots shake animation (not visible in static snapshot).
Dark Error State
"Invalid PIN. Please try again." in posError color. PIN dots reset to empty.
Light Lockout State
After 5 failed attempts. "Too many attempts. Try again in 30 seconds." Numpad disabled.
Dark Lockout State
Rate limiting enforced. Matches backend: 5 failures = 30s lockout.

Extra-large dynamic type. Buttons and text scale appropriately.
