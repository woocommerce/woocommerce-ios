# Local Operator Presentation

Small React presentation site for the Local Operator Mode feature story.

## Run locally

```bash
cd /Users/toupper/Projects/Repos/woocommerce-ios/docs/local-operator-presentation
npm install
npm run dev
```

The dev server is configured for `http://127.0.0.1:4173`.

## Purpose

Use this site to present:

- the product problem
- the local-first reasoning
- the role and capability model
- the shared-device flows
- what is already implemented
- known limits before backend roles exist
- the migration path toward remote enforcement
