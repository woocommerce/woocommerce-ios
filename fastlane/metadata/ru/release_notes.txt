Доставка в ЕС стала проще: теперь в таможенных декларациях при необходимости запрашиваются SKU, код производителя и код GTIN/EAN для каждого товара. Настройка очных продаж теперь работает корректно и для магазинов, не использующих WooPayments или Stripe. При оформлении этикеток для доставки указывать номер телефона получателя для внутренних заказов теперь необязательно.
